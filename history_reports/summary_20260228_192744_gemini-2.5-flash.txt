## High-Value Content Report: Procedural/How-To - Building an AI Agent from Scratch in Python

This video provides a **beginner-friendly, step-by-step tutorial** on how to build a functional **AI agent in Python** using popular frameworks like **LangChain**, integrating various Large Language Models (LLMs) and tools.

### 1. Video Goal
The primary goal is to guide viewers through the process of creating an AI agent from scratch, demonstrating how to:
*   Utilize **LangChain** for agent development.
*   Integrate different **LLMs** (e.g., Claude, GPT).
*   Provide the agent with access to **external tools**.
*   Structure the agent's output for programmatic use.

### 2. Project Demo Overview: A Research Assistant
The tutorial showcases building a **Research Assistant** agent capable of:
*   Accepting a research query (e.g., "tell me about Lang chain and its applications").
*   Accessing tools like **Wikipedia** and **DuckDuckGo Search** to gather information.
*   Displaying its **thought process** during research.
*   Generating structured output including a **topic**, **summary**, **sources**, and **tools used**.
*   Saving the comprehensive research output to a **timestamped text file**.

### 3. Prerequisites & Environment Setup

*   **System Requirements:**
    *   **Python 3.10 or above** installed on your system.
    *   A code editor (e.g., **Visual Studio Code** is recommended).
*   **Project Setup:**
    *   Create a new project folder (e.g., `AI agent tutorial`).
    *   Create a `requirements.txt` file in the project root containing the necessary **7 Python dependencies**.
    *   Initialize and activate a **Python virtual environment** within the project folder:
        *   `python -m venv venv`
        *   **Mac/Linux:** `source venv/bin/activate`
        *   **Windows:** `venv\Scripts\activate`
    *   Install dependencies: `pip install -r requirements.txt` (while the virtual environment is active).
*   **Project File Structure:**
    *   `main.py`: For the core agent logic.
    *   `tools.py`: To define and manage agent tools.
    *   `.env`: To securely store API keys for LLMs (e.g., OpenAI, Anthropic).
*   **API Keys:** Obtain and configure API keys for your chosen LLM (e.g., OpenAI API Key for GPT models, Anthropic API Key for Claude models). These will be loaded using `load_dotenv()` from the `.env` file.

### 4. Core Components & Step-by-Step Implementation

*   **LLM Integration:**
    *   Import `ChatOpenAI` (for GPT) or `ChatAnthropic` (for Claude) from `langchain_openai` or `langchain_anthropic`.
    *   Initialize the LLM by specifying the desired **model** (e.g., `GPT-3.5-turbo`, `GPT-4`, `Claude 3.5 Sonnet`). The video uses `ChatAnthropic` due to OpenAI rate limits.
    *   Basic LLM interaction is demonstrated using `llm.invoke("query")`.
*   **Structured Output with Pydantic:**
    *   Import `BaseModel` from `pydantic` and `PydanticOutputParser` from `langchain_core.output_parsers`.
    *   Define a Python class (e.g., `ResearchResponse`) that inherits from `BaseModel` to specify the **exact schema** for the LLM's output (e.g., `topic: str`, `summary: str`, `sources: list[str]`, `tools_used: list[str]`).
    *   Create a **PydanticOutputParser** instance, passing your defined `ResearchResponse` model, to convert the LLM's string output into a structured Python object.
*   **Prompt Engineering:**
    *   Import `ChatPromptTemplate` from `langchain_core.prompts`.
    *   Construct a `ChatPromptTemplate.from_messages` that includes:
        *   A **system message** defining the agent's role (e.g., "You are a research assistant...").
        *   Crucially, an instruction to **"wrap the output in this format and provide no other text"**, using format instructions generated by the `PydanticOutputParser`.
    *   Use `prompt.partial(format_instructions=parser.get_format_instructions())` to inject the output schema into the prompt.
*   **Agent Creation:**
    *   Import `create_tool_calling_agent` from `langchain.agents`.
    *   Instantiate the agent by passing the configured `llm`, the engineered `prompt`, and a list of `tools` (to be defined).
    *   Execute the agent using an `AgentExecutor` chain.
    *   Implement a **`try-except` block** to robustly handle potential errors in parsing the LLM's response.
*   **Adding External Tools:**
    *   Import pre-built tools from `langchain_community.tools` and `langchain_community.utilities`.
    *   Examples include:
        *   **`WikipediaQueryRun`** (using `WikipediaAPIWrapper`) for Wikipedia searches.
        *   **`DuckDuckGoSearchRun`** for web searches (a free alternative to Google Search).
    *   These tools are initialized and provided to the agent.
*   **Creating Custom Tools:**
    *   Any Python function can be converted into a tool.
    *   Import `Tool` from `langchain_tools`.
    *   Define a Python function (e.g., `save_to_txt`) that performs a specific action (e.g., saving structured data to a file).
    *   Wrap the function as a tool: `save_tool = Tool(func=save_to_txt, name='save_text_to_file', description='A clear description of what the tool does')`.
    *   Add custom tools to the agent's tool list.

### 5. Key Takeaways & Functionality

*   **Predictable Output:** The use of Pydantic models ensures that LLM responses are structured and typed, allowing for reliable programmatic access (e.g., `structured_response.topic`).
*   **Enhanced Capabilities:** Integrating various tools empowers the AI agent to perform actions beyond simple text generation, such as web searching and file operations, making it highly versatile.
*   **Extensibility:** The modular design with LangChain allows for easy addition of more LLMs, tools, and complex functionalities, providing a strong foundation for advanced AI agent development.
